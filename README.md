## 🚀 Getting Started

### View Locally

1. Clone this repository:
```bash
git clone https://github.com/dikshapidhadiya/portfolio.git
cd portfolio
```

2. Open the portfolio in your browser:
   - Open `index.html` for the main portfolio website
   - Open `resume.html` for the resume page

### File Structure

```
├── index.html          # Main portfolio homepage
├── resume.html         # Resume/CV page
├── style.css          # Main styles
├── resume.css         # Resume page styles
├── script.js          # JavaScript functionality
└── README.md          # This file
```
